# 構築相談スキル

ポケモンチャンピオンズの構築相談に、**実際に計算した数字で**答える。

このスキルの目的は「Claudeがポケモンの知識で語らないようにすること」。
種族値や相性の記憶で答えると必ず間違える。同梱のスクリプトを通した数字だけを使う。

## 絶対の約束

- **ダメージ判定を自分で計算しない。** 「たぶん確2」のような発言をしない。
  必ず `scripts/consult.py` を実行し、その出力に書かれた判定だけを引用する。
- **出力に無い相手のことを断定しない。** 環境上位45位までしかデータが無い。
  圏外のポケモンを聞かれたら、データが無いことを言う。
- **使用率データの月を最初に確認して、相談の冒頭で伝える。**
  古い環境の話をしていると気づけなくなる。

## 全体の流れ

### 1. パーティを `party.txt` の書式にする

3通りある。

**(a) ユーザーが party.txt を持っている** … そのまま使う。

**(b) 画像しかない** … 画像から4行フォーマットに書き起こす（書式は下記）。
実数値はゲーム内のステータス画面の値（メガシンカ**前**）をそのまま書く。

**(c) まだ育てていないポケモンを軸にしたい** … 使用率データから型を起こす。

```bash
python3 scripts/seed_party.py メガスターミー メガメガニウム:HC > 軸.txt
```

`名前:型` で配分パターン（`AS`、`HC` など）を指定できる。省略すると最頻の型。
環境で最も使われている配分・性格・特性・持ち物・技が出るので、そこから調整する。
出力に `# ★特性を確認すること` が付いていたら、ユーザーに確認する。

**6体揃っていなくてよい。** 軸2体だけのファイルでも計算できる。
むしろ軸だけの状態から始めるのがこのスキルの主な使い道。

### 2. 計算する

```bash
python3 scripts/consult.py --party 軸.txt --candidates -o 結果.md
```

- `--party` を省くと同梱の `party.txt`（既定のパーティ）を使う
- `--candidates` は空き枠の候補を出す。枠が埋まっている相談では省いてよい
- `--top 30` で相手を上位30位に絞れる（話を絞りたいときだけ）

書式エラーがあればその場で止まり、何行目の何が悪いか出る。直して通るまで繰り返す。

### 3. 出力を読んで答える

`結果.md` に入っているもの:

| 節 | 使いどころ |
|---|---|
| 駒ごとの成績 | どの枠が弱いか。「落とせる」「1発で落ちる」「素早さ勝ち」「仕事あり」の数 |
| 重い相手 | 対面から仕事ができる駒が1つも無い相手。**相談の中心はここ** |
| 空き枠の候補 | 重い相手を見られる型を環境上位から探した並び |
| 対面表 | 全行 × 全駒の `与判定/被最大% 素早さ` |
| 素早さ | 環境の実数値ラインと、そこを抜いている駒 |
| 環境の分布 | タイプ・持ち物の分布 |
| 同時採用 | 相方として何が組まれているか |

### 4. 案を比べる

案を変えたら**必ず計算し直す**。頭の中で差分を推測しない。

```bash
python3 scripts/consult.py --party 案B.txt --candidates -o 案B.md
```

「重い相手が15行 → 9行に減った」のように、行数で比較して伝える。

## party.txt の書式（1体4行、体と体の間は空行）

```
1行目  ポケモン名 @ 持ち物
2行目  性格 / 特性
3行目  実数値 H-A-B-C-D-S
4行目  技 / 技 / 技 / 技        （1〜4個）
```

- `@` と ` / ` の前後には**必ず半角スペース**。実数値の区切りだけ `-` でスペース無し
- ポケモン名は `data/dex.csv` の name 列と完全一致。リージョンフォームは `ダイケンキ(ヒスイ)`
- **メガ形態の名前は書かない。** 通常形態の名前を書いて、持ち物にメガストーンを持たせる。
  メガ／非メガの2件が自動で作られる
- 特性も**通常形態のもの**を書く（メガの特性は計算側が差し替える）
- 実数値はレベル50・個体値31前提。1ポイント＝努力値8で、1能力最大32・合計66ポイント
- `#` で始まる行はコメント

## 数字の読み方（相談で必ず踏まえること）

- 判定は `確1`（確定1発）> `乱1` > `確2` > `乱2` > `確3` > `4発+`
- **対面1回の殴り合いしか見ていない。** 状態異常・天候・積み・交代読み・急所は入っていない
- 「仕事あり」＝1発で落とせて、かつ相手より先に動けるか1発では落ちない行の数
- 空き枠の候補は**対面性能だけ**で並べている。役割の重複、並びとしての相性、
  積みの通し方、サポートの噛み合いは見ていない。**絞り込みの材料であって答えではない**
- 候補は環境上位の型に限られる。圏外のポケモンを試すには、
  ユーザーに実数値と技構成を聞いて party.txt の書式で足してもらう

## 答え方

数字を並べるだけにしない。**どの枠をどうするかの判断**まで踏み込む。ただし、

- 判断の根拠は必ず出力の数字で示す（「メガゲンガーが重い15行のうち11行に出てくる」など）
- 対面表だけでは決まらないこと（役割の重複、選出の噛み合い）は、そう言ったうえで意見を述べる
- ユーザーが既に決めている軸を否定しない。軸は前提として、空き枠の話をする

## データを新しくしたいと言われたら

このスキルに入っている使用率データは、登録した時点のスナップショット。
更新するには元のリポジトリ（cola-jp/Champion-VS）でデータを差し替えてから
`python build/make_skill.py` を流し直し、出てきた zip を登録し直す。
スキルの中のファイルを手で書き換えても、次に作り直したときに消える。
