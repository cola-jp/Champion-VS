# ============================================================================
# パーティ定義ファイル（ポケモンチャンピオンズ 対面ダメージ表）
#
# 読み込むのは build/party.py（Python）と assets/engine.js（ブラウザ）の両方。
# 書式が合わないとビルドが止まる。ブラウザの party.html からも編集・書き出しできる。
#
# ---------------------------------------------------------------- 書式
# 1体につき4行。体と体の間は空行で区切る。# で始まる行はコメントで無視される。
#
#   1行目  ポケモン名 @ 持ち物
#   2行目  性格 / 特性
#   3行目  実数値 H-A-B-C-D-S
#   4行目  技 / 技 / 技 / 技        （1〜4個）
#
# **区切り記号の前後の空白は必須**。半角スペースを入れること。
#   OK : ギャラドス @ ギャラドスナイト     NG : ギャラドス@ギャラドスナイト
#   OK : ようき / いかく                  NG : ようき/いかく
#   OK : たきのぼり / じしん              NG : たきのぼり/じしん
# 実数値の区切りだけは "-"（空白なし）で、必ず6つ。持ち物を空にはできない。
#
# ---------------------------------------------------------------- 各行の中身
# ポケモン名 … data/dex.csv の name 列と完全一致させる。
#               リージョンフォームは「ダイケンキ(ヒスイ)」のように括弧付き。
#               メガ形態は下記のとおり自動生成されるので、ここには通常形態を書く。
# 持ち物     … 表示に使うほか、次の2つだけ計算に影響する。
#               ・メガストーン（名前に「ナイト」を含み、"メガ"+ポケモン名 が図鑑にある）
#                 → メガ形態と非メガ形態の2件が自動生成される
#               ・こだわりスカーフ → 素早さ1.5倍が自動で掛かる
#               ・いのちのたま     → ダメージ1.3倍が自動で掛かる
# 性格       … 日本語表記（ようき・いじっぱり・ひかえめ など全20種）。
# 特性       … そのポケモンが持ちうる特性のいずれか。data/dex.csv の abilities 列
#               （"/" 区切り）に含まれていないとエラーになる。
#               メガ形態の特性は自動で差し替わるので、通常形態の特性を書く。
# 実数値     … **ゲーム内のステータス画面に表示される数値をそのまま**。
#               レベル50・個体値31が前提。メガシンカ前の値でよい（というより、そう書く）。
#               ここから能力ポイントを逆算するので、到達しない値はエラーになる。
# 技         … data/moves.csv の name 列と完全一致。1〜4個。
#
# ---------------------------------------------------------------- 努力値の決まり
# このゲームは「能力ポイント」制で、1ポイント = 努力値8。
# 1ステータス最大32ポイント、1体あたり合計66ポイントまで。
# 1ポイントで実数値がちょうど1上がるので、実数値からポイントは一意に決まる。
# 上限を超える実数値や、到達しない実数値を書くとビルド時にエラーになり、
# そのステータスで取りうる値の一覧が表示される。
#
# ---------------------------------------------------------------- 確認方法
#   python build/generate.py          書式と実数値を検証する
#   python build/export_app_data.py   ブラウザ用データを作り直す
# ============================================================================
